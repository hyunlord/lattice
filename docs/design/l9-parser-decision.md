# L9 static parser decision

L9 explicitly requests static function-call analysis across JS/TS, Python, Go, Rust, Java/Kotlin and C#. The existing lexical declaration scanner cannot establish nested syntax, scope or callsite boundaries reliably. Add exactly pinned `web-tree-sitter@0.25.10` and `tree-sitter-wasms@0.1.13` for CLI analysis, never to browser assets. Retain lexical extraction as explicitly limited fallback when a grammar cannot parse a region. AST structure alone is not proof of binding: resolve calls only through lexical scope, explicit imported bindings or established static owners; unknown receivers/overloads/dynamic dispatch remain unresolved or estimated.

The [official web binding documentation](https://github.com/tree-sitter/tree-sitter/blob/v0.25.10/lib/binding_web/README.md) defines Parser.init, Language.load and parse, and notes WASM can be slower than native bindings. Native bindings require node-gyp/prebuild install handling and per-language ABI coordination. The selected packages install under npm ci --ignore-scripts without a compiler, install hook, API key or runtime network. [Microsoft's WASM bundle](https://github.com/microsoft/vscode-tree-sitter-wasm) is smaller but lacks Kotlin.

The grammar supplier is [tree-sitter-wasms](https://github.com/Gregoor/tree-sitter-wasms), separate from upstream tree-sitter. Its [pinned upstream lock](https://github.com/Gregoor/tree-sitter-wasms/blob/3e88dc9e36b4e8bf752ce53bea61e4b67282a2bb/pnpm-lock.yaml) records JS0.20.4, TS/TSX0.20.5, Python0.21.0, Go0.20.0, Rust0.20.4, Java0.20.2, Kotlin0.3.8 and C#0.20.0. These older grammars do not guarantee all modern language syntax. ERROR/missing regions must be diagnosed and excluded from exact-call claims. Macro expansion, reflection, dependency injection and runtime callbacks are not fabricated.

Independent pre-adoption probes passed simple function/call parsing for all nine grammars on Node20.20.2,22.23.3 and24.21.0, including npm-pack installation into a separate consumer. The two packages total6,237,758 compressed bytes and57,542,691 installed bytes; selected nine grammar binaries total15,393,652bytes. These are parser compatibility probes, not L9 call-precision or full-build performance evidence. Package-lock integrity pins the distribution; grammar hashes are recorded alongside the parser cache identity. Initialize once per process, delete parse trees after serializable facts are extracted, and reuse unchanged facts through content-addressed cache. The large-repository five-minute gate remains mandatory.

The web binding declarations require global EmscriptenModule types. Add exact dev-only @types/emscripten1.41.6 to the CLI compiler types, preserving strict dependency checking rather than enabling skipLibCheck. No runtime/browser payload is added by this type package.
