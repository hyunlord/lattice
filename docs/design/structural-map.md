# Reading a repository without a lens

Static imports preserve what the source actually declares. A package or namespace import points from the importing module to one package node; `contains` records package membership separately. Membership is not evidence that the importer uses every member file. Named, resolved file/type imports retain file targets. Unresolved imports remain diagnostics. These are static declarations, not runtime calls.

Folder arrows count distinct importing source paths. Repeated imports from one file count once for each destination chunk. Folding folders reaggregates source sets, rather than adding child totals. A namespace spanning multiple directories remains a logical package, not a claim that each physical directory is independently used.

The initial map contains at most nine chunks. Folder navigation exposes smaller chunks and their contents. Acyclic dependencies run from consumers above to foundations below; strongly connected components are explicitly identified. The focused panel retains dependencies beyond the currently drawn page. Names break at path separators, with complete identity retained.

Descriptions use source documentation first sentences, matching README sections, or up to three public declaration names ranked by static identifier frequency. They retain path and line evidence; a first function's documentation does not become a package-purpose claim. Identifier frequency is a lexical heuristic, not compiler resolution or verified call count. Empty descriptions offer the external Claude/Codex skill. Lattice embeds no model or API.

The viewer currently uses Korean. Static source quotations retain the source's language; external AI summaries use the viewer language and remain labeled, hash-bound interpretations. Unknown execution status is hidden when every item is unknown; it never becomes implementation evidence.

L8 acceptance measures independent import counts, initial chunk count, browser geometry, word wrapping, description coverage, console errors, mobile overflow and build time. Claude's held-out comprehension review and the user's final judgment remain separate from those mechanical checks.
