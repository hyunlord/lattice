# Generic home structure and recent change concentration

Home now combines the current layer's visible inventory and typed facet distribution with materialized structural findings and recent exported history. Facet values keep JSON identity and count each node once per value, even when multiple rules emit the same classification. Links use the list's exact typed filters.

Automatic findings are ordinary graph findings, generated during build for the CLI, export and future MCP consumers. They have computed basis and no gates. Isolation and hub degree count unique incident edge IDs within one layer; self-loops count once and cross-layer correspondence is excluded. Hubs report the highest ten and the total connected population. These findings include hidden kinds, with that broader scope explained on Home. Broken-reference findings retain exact diagnostic provenance and nearest source owners; external references, external-or-unresolved package imports, stale Graft data and sourceless/unowned diagnostics are not silently classified as broken local references. The complete CLI diagnostic stream remains available.

Home compares the final two snapshots in manifest observation order, explicitly distinguishing that order from Git chronology or complete repository history. It shows commit, snapshot and coverage labels, comparison links, directory counts and original before/after sources. Current directory inventory counts actual current node IDs. Semantic node changes and source-path relocations contribute to recent areas; a relocated node counts once in both old and new directories. Revision, source hash and line shifts alone do not create movement. Existing content comparison still ignores source-only changes. No-history exports show their actual current source inventory, never a fabricated zero-change trend.
