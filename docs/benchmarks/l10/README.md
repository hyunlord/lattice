Rotate arm order by repository index to balance warm-environment effects. Evaluators receive answer-free frozen questions and access only to their designated pinned repository and permitted surfaces. They may not read reference answers, other arms, implementation history or external web pages. The map-only arm may use grounded snippets supplied by Lattice.
