# L11 fixed question shape

Each pinned repository receives these ten questions before product implementation. Replace X/A/R/Y/Z with one concrete source-selected target; preserve those targets after freeze. Reference answers are source-only and withheld from evaluation agents.

1. What does the repository do, and who calls or runs it?
2. Name the principal components and their responsibilities.
3. Which languages, build/framework systems and package boundaries organize it?
4. Where does the selected executable or public-library use begin?
5. Where is behavior X implemented? Name its component and definition.
6. Which internal components does A directly use, and what proves each direction?
7. For action R, give the source-supported call/dispatch path to its outcome; identify dynamic or unresolved boundaries.
8. If Y changes, which direct consumers are evidenced? Separate dependency from speculative behavioral impact.
9. Which tests or documented example exercise X, and how do they enter the implementation?
10. Where does Z enter and get handled or transformed?

Each answer has required atomic facts and path/line/hash evidence. Across all questions, accept equivalent source-grounded terminology and alternative valid tests/examples where the question permits them; do not require exact wording. Scores are0/1/2 (absent/incorrect, partial, complete with valid citations); invented connections cannot earn full credit. Honest unsupported-language disclosure is measured separately from factual correctness. Do not require five components when source supports fewer or invent executed flow from static reachability.
